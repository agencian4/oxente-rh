# Oxente, RH! — Site

Site estático (HTML + CSS + JS). Sem build.

## Deploy na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: Add New → Project → importe o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory: deixe em branco.
4. Deploy.

## Estrutura
- `index.html` — página completa (estilos e scripts embutidos; GSAP via cdnjs; fontes via Google Fonts)
- `img/` — fotos em WebP
